Role-driven reactive framework

Build UI with Roles

RoledJS is a lightweight reactive JavaScript framework where behavior is attached through roles instead of heavy components.

Reactive 

new Role("counter", {
  state: {
    count: 0
  },

  mount(el, state){
    el.on("click", () => {
      state.count++
    })
  },

  effect(el, state){
    el.text(`Count: ${state.count}`)
  }
})
